## 🚀 Featured Projects

### [Zukiru](https://zukiru.com) — Production Social Network

An X-style social platform designed, built, and deployed independently, end to end.

- **Backend:** Go, Gin, PostgreSQL
- **Frontend:** SvelteKit
- **Feed ranking:** Personalized recommendations combining follow-graph proximity, pgvector embeddings, recency, and engagement signals
- **Media pipeline:** Zero-trust upload validation, FFmpeg transcoding, WebP/H.264 renditions, and CDN-backed storage
- **Scalability:** Load-tested with 50,000 simulated concurrent users on production-equivalent infrastructure
- **Reliability:** PostgreSQL advisory locks, keyset pagination, single-flight token refresh, and CI-enforced OpenAPI contracts
- **Infrastructure:** Hetzner, Cloudflare Tunnel, R2, automated CI/CD

🔗 **[Visit zukiru.com](https://zukiru.com)**

### [Zuki](https://github.com/Tiberiu2007/zuki) — Modular C++20 Game Engine

A game engine built from scratch, with a focus on modular architecture, rendering abstractions, and performance.

- **16,300+ lines of C++20** across 17 independent library targets
- **Layered architecture:** Five enforced dependency layers
- **Rendering:** Vulkan backend with swapchains, SPIR-V pipelines, descriptor bind groups, render targets, materials, and a render graph
- **Graphics abstraction:** Backend-agnostic public APIs designed to support future D3D12 and Metal implementations
- **Entity Component System:** Archetype-based, struct-of-arrays storage with RTTI-free components and O(1) packed-row removal
- **Systems infrastructure:** X11 and Wayland backends, three custom allocators, and a deadlock-free work-sharing job system

🔗 **[Explore the source code](https://github.com/Tiberiu2007/zuki)**
